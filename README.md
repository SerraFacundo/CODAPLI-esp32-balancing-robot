# ESP32 Self-Balancing Robot

> Réplica del proyecto de PCBWay basado en ESP32 + NEMA17 + MPU-6050

## 🔧 Hardware
- ESP32 (ESP-WROOM-32)
- 2x Stepper Motor NEMA17 + drivers A4988
- MPU-6050 (giroscopio/acelerómetro)
- Servo MG-90S
- 2x Li-ion 18650 (7.2V en serie)
- Buzzer activo + 2x LEDs
